# X support

X is not patched by this repository. The current X build is
**12.39.0-prod.01** (`com.twitter.android`, versionCode 312390001), and the
maintained Morphe-compatible patch bundle for it is **Piko NewX**:

- Downloads: <https://github.com/crimera/piko-newx/releases>
- Source: <https://github.com/crimera/piko/tree/x-lite>
- Legacy X bundle (12.19.1): <https://github.com/crimera/piko/releases>

Piko NewX is GPL-3.0. It is a separate project; this repository does not
repackage it or ship X APKs.
